# Правила общения

- Обсуждаем код и решения уважительно, без оскорблений и дискриминации.
- Сообщаем факты, шаги воспроизведения и ограничения проверки.
- Не публикуем чужой закрытый код, персональные данные, ключи и session URL.
- Уязвимости отправляем через приватный канал из [SECURITY.md](SECURITY.md).
- Не выдаем рекламу, неподтвержденные результаты или чужую работу за собственную.

Сопровождающий проекта может закрыть обсуждение или ограничить участие при нарушениях. Эти правила действуют в issues, pull requests и обсуждениях репозитория.
