# Изменения

## 0.4.0

- AI-клиенты работают прямо с проектом и читают нужные файлы штатными инструментами; обязательные копии исходников, зависимостей и auth HOME удалены.
- Codex, Claude Code и Cursor сохраняют структурированные результаты: применение правок, проверка путей, исходных хешей и требований остаются за Executor.
- Новые checks выполняются локально без Docker. Старое имя `hardened` совместимо с локальным режимом; подготовка контейнеров отключена, recovery старых receipts сохранено.
- Общая политика имен, содержимого и `aiDenyGlobs` защищает контролируемые Flowcairn контекст, правки и артефакты. Документация прямо описывает ограничения защиты сторонних tools и scripts.
- Добавлен нативный Windows runtime: переносимые пути/файловые проверки, системное окружение и остановка дочерних процессов через Windows Job Object. Windows-проверки вынесены в отдельный CI job без WSL и Docker.
- Новая модель доступа требует обновленного согласия; старое согласие на ограниченный контекст не расширяется молча.

## 0.3.8

- Интерфейс перестроен для быстрой ориентации: задача, состояние проекта, граф и детали исполнения получили стабильную иерархию и понятные главные действия.
- На экранах от 1800 CSS px используется широкая рабочая компоновка с задачами слева, работой в центре и критериями или доказательствами справа. Дизайн ноутбука и мобильного интерфейса сохранен.
- Результаты, проверки, изменения и ресурсы показываются из контрактов Executor без вымышленных данных; устаревшие или недостоверные доказательства не отображаются как подтвержденные.
- Первый запуск и готовность интерфейса оформлены понятной терминальной карточкой с корректным выводом в узких терминалах, CI и режиме без цвета.
- Добавлены UI-регрессии для состояний выполнения, широких экранов, смены темы, мобильной компоновки и сохранения пользовательского ввода при изменении ширины.

## 0.3.7

- Codex CLI обнаруживается через `PATH`, а совместимость определяется по параметрам безопасного запуска, без списка разрешенных версий.
- Версии plugin manifests синхронизированы с версией пакета.

## 0.3.6

- Исправлен lifecycle выполнения: startup supervisor, подтверждение termination и сохранение причин ошибок.
- Добавлены однозначные исходы `failed` и `cancelled`; `uncertain` остается только для реально неподтвержденного состояния.
- Удален onboarding-шаг запуска проверок; `trusted-local` стал default для новых локальных проектов с hash-привязкой scripts.
- Обновлены русские сообщения ошибок, proof UI и lockfile зависимостей.

## 0.3.5

- Естественная задача запускается одной кнопкой. До согласования плана анализ может самостоятельно запросить дополнительные файлы и продолжиться после проверки путей Executor.
- Выбор начального контекста учитывает заголовок, точные пути, новые файлы и неоднозначные имена. Явно указанная папка больше не теряет соседние файлы из-за упоминания вложенного файла.
- Уточнение создает новую неизменяемую версию с сохранением требований и истории; права на запись не переносятся без согласования. Подтвержденная смысловая неопределенность отображается отдельно от неподтвержденной остановки процесса.
- Добавлены проверки устаревшего выбора файлов, гонки снимка, автоматического исследования, ограничений доступа и продолжения задачи. Подготовка списка контекста проверена на 20 000 именах.

## 0.3.4

- Обновлена библиотека проверки данных Zod с 4.4.3 до 4.6.5 после успешных проверок на Ubuntu и macOS.

## 0.3.3

- Основной UI перестроен вокруг задачи: стабильный shell без скачка загрузки, отдельный расширенный граф, одна основная прокрутка на ноутбуке и панель запусков на мобильном.
- Добавлены текстовые loaders для загрузки, выполнения и остановки с поддержкой reduced motion.
- Остановка немедленно отображается в UI и остается в состоянии `stopping` до подтвержденного termination; неподтвержденная остановка показана отдельно.
- Ошибки и предупреждения объясняются по-русски, а machine codes и исходная диагностика доступны в свернутых технических деталях.
- Интерфейс использует локальные variable subsets Manrope Latin/Cyrillic с лицензией SIL OFL-1.1.

## 0.3.2

- Большие снимки проекта сохраняются отдельно от истории запуска. Flowcairn больше не останавливает планирование из-за внутреннего лимита в 10 000 файлов.
- Экран проблем объясняет причину, влияние и следующий шаг понятным русским языком. Технические коды не показываются вместо объяснения.
- Обновлена типографика и визуальная иерархия экранов статуса, ошибок и восстановления.

## 0.3.1

- README сокращен до назначения, установки и основных ограничений Flowcairn. Демонстрационные анимации и баннер удалены.
- Инструкции для пользователей отделены от архитектуры и материалов для разработчиков инструмента.
- Установка по-прежнему работает в текущем Node.js-проекте, в том числе без Git. План требует согласия до изменений; обязательные требования получают отдельные проверки.
- Старый валидный блок Flowcairn в `AGENTS.md` или `AGENTS.override.md` мигрируется безопасно; поврежденные блоки остаются блокировкой.
- Ошибки CLI показывают причину, место проблемы и следующий шаг, сохраняя стабильный machine code.
