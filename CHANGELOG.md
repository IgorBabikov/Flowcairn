# Изменения

## 0.2.8 — готовится к публикации

- Добавил честные capability states для Claude Code и Cursor: обнаружение больше не выглядит как готовый execution adapter.
- CLI объясняет, почему обнаруженный Claude Code или Cursor пока не появляется среди провайдеров выполнения.

## 0.2.7 — готовится к публикации

- Закрыл security-блокер local checks: новый проект больше не запускает scripts репозитория автоматически.
- Добавил безопасный default `checkMode: "none"`, Docker-режим `hardened` и отдельное согласие для `trusted-local`.
- Синхронизировал версию root `package-lock.json` с `package.json`.

## 0.2.6 — готовится к публикации

- Обычные `typecheck`, `lint`, `test` и `build` теперь выполняются в выделенной Git worktree и не требуют Docker.
- Docker сохранен как дополнительный усиленный режим; локальный receipt явно помечает отсутствие контейнерной изоляции.
- `init` больше не меняет командный `.gitignore`: локальное состояние исключается через `.git/info/exclude` и корректно убирается при uninstall.

## 0.2.5 — готовится к публикации

- Убрал обязательный ввод ID модели при обычной настройке Codex: Flowcairn использует выбор модели и усиления из самого Codex.
- Добавил native manifests и capability registry для Codex, Claude Code и Cursor без дублирования Skills и без ложного заявления об execution support.

## 0.2.4

Опубликовано в npm 15 сентября 2026 года.

## 0.1.0

Первый отдельный релиз Flowcairn.

- Локальный Graph Runtime и React Flow control UI с русским языком по умолчанию.
- Project profile и разделение установленного runtime и рабочего проекта.
- Immutable plans, human gates, receipts, проверка scope и trusted patch application.
- Codex CLI adapter и отдельный tool-free OpenAI API adapter.
- Registered checks в Docker, bounded retry/recovery и новая версия плана.
- Полный review evidence bundle до 512 KiB с проверкой привязки ответа.

Ранняя версия. Автоматическая декомпозиция большой задачи, удаленное многопользовательское управление и поддержка всех ОС/репозиториев не заявляются. Подробности: [ограничения](docs/LIMITATIONS.md).
