# Изменения

## 0.2.20

- Добавил совместимость с Codex CLI 0.154.0, сохранив проверку версии и sandbox-возможностей.
- В режиме CLI читаются только модель и усиление из пользовательского config.toml и передаются явно; hooks и остальные настройки не импортируются.
- Убрал ложное отображение medium и обещание считывать выбор активного чата VS Code.
- При первоначальной интерактивной настройке CLI и настройки модели проверяются до сохранения профиля.

## 0.2.19

- Исправил переносы и обрезку раскрытого статуса проекта на desktop и mobile.
- Причина недоступности исполнителя показывается в основной панели.
- Для готового анализа добавлена кнопка запуска, доступная только при разрешении backend.

## 0.2.18

- Согласовал общий лимит Skills с четырьмя допустимыми project Skills; инструкции сохраняются полностью.
- Skills проверяются до записи Orchestrator, чтобы ошибка не оставляла частичную регистрацию.
- Добавил восстановление старой незавершенной регистрации только при неизмененном snapshot и отсутствии попыток выполнения.
- После ошибки создания UI обновляет контекст проекта, сохраняя исходную ошибку и текст задачи.

## 0.2.17

- Ускорил сборку snapshot больших проектов: Git-объекты читаются пакетами вместо двух отдельных процессов на каждый файл.
- Сохранил ограничения размера, исключение чувствительных файлов и проверку бинарного формата ответа Git.

## 0.2.16

- Сборка снимка проекта и регистрация Orchestrator выполняются в отдельных процессах, чтобы HTTP-сервер мог отвечать во время подготовки задачи.
- Добавил тайм-ауты, завершение дочерних процессов и понятную ошибку при слишком долгой подготовке.
- Форма показывает индикатор подготовки; повтор после ошибки сохраняет ID исходного запроса.

## 0.2.15

- Добавил отдельную проверку совместной работы `AGENTS.md` и `AGENTS.override.md` при восстановлении интеграции.

## 0.2.14

- Flowcairn безопасно восстанавливает журнал для собственного неизмененного orphan-блока интеграции.
- Чужие, измененные и неоднозначные блоки по-прежнему останавливают интеграцию без удаления правил проекта.

## 0.2.13

- Исправил счетчик шагов onboarding: теперь все пять шагов показываются как «из 5».
- Добавил безопасное восстановление журнала существующей интеграции без перезаписи правил проекта.

## 0.2.12

- Исправил запуск в проектах с отслеживаемым `.npmrc`: файл не попадает в source bundle и изолированный Graph worktree.

## 0.2.9 — готовится к публикации

- Добавил реальные Claude Code и Cursor adapters: проверенный CLI, strict structured output, отдельное consent на передачу ограниченного контекста, immutable plan и receipt.
- Claude запускается без tools через официальный `--tools ""`; Cursor — в private workspace с официальными `--sandbox enabled --mode plan`.

## 0.2.8 — готовится к публикации

- Добавил capability states и нативные manifests Claude Code/Cursor.

## 0.2.7 — готовится к публикации

- Закрыл security-блокер local checks: новый проект больше не запускает scripts репозитория автоматически.
- Добавил безопасный default `checkMode: "none"`, Docker-режим `hardened` и отдельное согласие для `trusted-local`.
- Синхронизировал версию root `package-lock.json` с `package.json`.

## 0.2.6 — готовится к публикации

- Обычные `typecheck`, `lint`, `test` и `build` теперь выполняются в выделенной Git worktree и не требуют Docker.
- Docker сохранен как дополнительный усиленный режим; локальный receipt явно помечает отсутствие контейнерной изоляции.
- `init` больше не меняет командный `.gitignore`: локальное состояние исключается через `.git/info/exclude` и корректно убирается при uninstall.

## 0.2.5 — готовится к публикации

- Убрал обязательный ввод ID модели при обычной настройке Codex: Flowcairn использует выбор модели и усиления из самого Codex.
- Добавил native manifests и capability registry для Codex, Claude Code и Cursor без дублирования Skills и без ложного заявления об execution support.

## 0.1.0

Первый отдельный релиз Flowcairn.

- Локальный Graph Runtime и React Flow control UI с русским языком по умолчанию.
- Project profile и разделение установленного runtime и рабочего проекта.
- Immutable plans, human gates, receipts, проверка scope и trusted patch application.
- Codex CLI adapter и отдельный tool-free OpenAI API adapter.
- Registered checks в Docker, bounded retry/recovery и новая версия плана.
- Полный review evidence bundle до 512 KiB с проверкой привязки ответа.

Ранняя версия. Автоматическая декомпозиция большой задачи, удаленное многопользовательское управление и поддержка всех ОС/репозиториев не заявляются. Подробности: [ограничения](docs/LIMITATIONS.md).
