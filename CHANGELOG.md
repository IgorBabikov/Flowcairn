## 0.2.0

Опубликовано в npm 14 сентября 2026 года.

- Реализовал три поля задачи, отдельный анализ, уточняемый план, одно согласование и ограниченное автономное выполнение.
- Подключил core/domain/project Skills с явными областями и этапами, сохранил правила владельца по тестам.
- Добавил обнаружение проектных инструкций, managed-активацию и безопасное снятие интеграции.
- Упростил открытие UI, добавил Yarn 4 для проверок и явные границы Linux/WSL2/Bun.
- Сохранил компактную раскладку графа, показал выбранные Skills/checks и согласие на исходный снимок.

- Сделал этапы графа понятнее: русские названия, состояния выполнения и активные связи.
- Упростил настройку первого запуска с сохранением явных разрешений.
- Добавил готовый интерфейс в Git для установки из main без сборки и postinstall.

## 0.1.0

Первый отдельный релиз Flowcairn.

- Локальный Graph Runtime и React Flow control UI с русским языком по умолчанию.
- Project profile и разделение установленного runtime и рабочего проекта.
- Immutable plans, human gates, receipts, проверка scope и trusted patch application.
- Codex CLI adapter и отдельный tool-free OpenAI API adapter.
- Registered checks в Docker, bounded retry/recovery и новая версия плана.
- Полный review evidence bundle до 512 KiB с проверкой привязки ответа.

Ранняя версия. Автоматическая декомпозиция большой задачи, удаленное многопользовательское управление и поддержка всех ОС/репозиториев не заявляются. Подробности: [ограничения](docs/LIMITATIONS.md).
