# Статические ассеты RPG

Набор `d1-static-1`: пять отдельных растров для изометрического мира Flowcairn. Авторский набор сгенерирован с помощью OpenAI ImageGen по согласованному визуальному направлению. Внешние стоковые ассеты, шрифты и логотипы в набор не добавлялись. Общие условия репозитория см. в корневом LICENSE. Подтверждение исключительности изображений не заявляется.

## Файлы и размещение

Единственный источник размеров, SHA-256, pivot, сцен, hotspots и дорожек мира — [world.json](world.json). Пути в нем относительны этой папке. Hash относится к точным байтам PNG; не менять файл без обновления manifest. Отдельные материалы DOM-поверхностей перечислены ниже; они не меняют геометрию мира.

| Файл | Размер | Назначение |
| --- | --- | --- |
| world.png | 1536×1024 RGB | Площадь, три здания, дорожки и мост; без персонажей и интерфейса |
| workshop-room.png | 1536×1024 RGB | Интерьер Мастерской; свободная зона для героя, наставника и книги |
| archive-room.png | 1536×1024 RGB | Интерьер Архива; свободная зона для героя и каталога |
| hero-idle.png | 1254×1254 RGBA | Герой, один статический кадр NW, прозрачный фон |
| mentor-idle.png | 1254×1254 RGBA | Наставник, один статический кадр SE, прозрачный фон |

Координаты сцен совпадают с пикселями подложек: начало сверху слева, x вправо, y вниз. При масштабировании сохранять пропорции (`contain`); DOM не масштабируется вместе со сценой. Buildings уже нарисованы в world.png, поэтому повторно рисовать отдельные фасады не нужно. Движение допустимо только по заданным передним дорожкам; обход зданий сзади не предусмотрен.

`anchorPx` фигур — точка опоры в исходном PNG. `visibleBoundsPx` — `[left, top, right, bottom]`, правая и нижняя границы исключены; измерены по alpha >16, потому что за силуэтом есть визуально незначимые пиксели alpha=1. Bounds служат для масштаба, а не для удаления alpha. Масштаб фигуры = нужная видимая высота / (bottom−top). Положение полного PNG = позиция ног − anchorPx×масштаб. Не масштабировать по полному квадрату PNG: вокруг фигур много прозрачного поля.

В мире высота героя 90 px, в интерьерах 160 px; для наставника Мастерской 168 px. Интерьерные значения отражают более близкий масштаб комнаты. Тени под ногами рисует renderer отдельно. Изображения не содержат готовой анимации, directional atlas или нескольких кадров; не зеркалить фигуры с асимметричными вещами.

## Границы использования

- Background — слой 0; отдельные тени и персонажи выше; текст, статусы, формы, книги и код — DOM. На изображениях нет baked UI или программного кода.
- Hero/NPC не выполняют команды. Переход в помещение и открытие книги не меняют состояние executor.
- `navigation.edges` двусторонние; `radiusPx` задает коридор вокруг отрезка, на мосту он уже. Клик рядом с дорогой проецируется на маршрут; вне разрешенной зоны отклоняется. Мост, стены и кусты не становятся проходимыми по bounding box изображения.
- `hotspots` содержат отдельные hit polygons, DOM label anchors и arrival node. Нажатие фасада ведет к входу; разрешение работы определяется отдельным runtime-контрактом.
- При загрузке нужны world+hero; комнаты и mentor загружаются по запросу. Недоступная картинка не блокирует DOM-команды.
- Это статический набор D1. Полноценные направления и ходьба требуют отдельного D2. Наличие файлов не доказывает готовность игрового интерфейса или результатов исполнения.

Проверены размеры, декодирование, alpha и hashes; вручную просмотрены пять изображений, наложение маршрута и персонажей, светлая и темная подложки фигур. Движение, runtime-команды и browser acceptance целевого приложения проверяются при интеграции.

Исходные PNG сохранены без перекрашивания и композитинга; native provenance metadata сохранены. Персональные пути, генерационные prompts, данные пользовательских задач и история внутренних запусков в этот документ/manifest не включаются.

## Материалы DOM-поверхностей

| Файл | Размер | SHA-256 |
| --- | --- | --- |
| ui-codex.png | 1536×1024 RGBA | `8716d1ac447a1bf15da7e868a4cde7bd63b129b96de8c9ab2c906cd38ef115cb` |
| ui-quest-scroll.png | 1024×1536 RGBA | `be854c0d1a3f660f82f091af22d9fc5fa7369f663c557db865f774491d2803a4` |

Первый файл — пустая раскрытая книга, второй — пустой свиток. Машинные metadata содержатся в optional `world.json.uiAssets` с ключами `ui-codex` и `ui-quest-scroll`; геометрия и поля основного мира сохранены. Нормализованные чистые области описаны в RPG-EXPERIENCE.md. Созданы native ImageGen; вне предметов настоящая alpha, проверенная численно и в browser compositing поверх мира. Цвет RGB в полностью прозрачных пикселях не является подложкой: не flatten изображения. Читаемый текст, код, кнопки и формы накладываются отдельным DOM-слоем без перспективного искажения.

Композиция, clean areas и поведение описаны в [RPG-EXPERIENCE.md](../../../../docs/RPG-EXPERIENCE.md). Подключение этих двух файлов к safe serving/build allowlist — отдельная интеграция; само присутствие PNG не означает, что приложение уже их использует.
