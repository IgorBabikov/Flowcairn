# Что проверено в текущей рабочей версии

Проверки выполнены на macOS с Node.js 22.13.1 для локального кандидата `0.3.5` после исправления lifecycle. Они подтверждают перечисленные сценарии, но сами по себе не означают завершение произвольной пользовательской задачи или публикацию пакета.

| Проверка | Результат |
| --- | --- |
| Полный Node test suite | Успешно вне sandbox; проверки локального HTTP и fresh-install требуют localhost и npm cache. Пять platform/Docker-сценариев пропущены средой |
| `npm run typecheck` и `npm run lint` | Успешно |
| `npm run build` | Собран UI и локальные Manrope Latin/Cyrillic assets |
| `npm run test:ui` | Chromium: 100 успешно, 1 пропущен; всего 101 |
| `npm run test:proof-browser` | Реальный WorkflowService, HTTP и Chromium: требования, результаты проверок, устаревание результата и личная приемка |
| `npm run check:package` | В локальном устанавливаемом архиве 143 файла; runtime, Skills, CLI и UI на месте |
| `npm run check:public` | 293 публичных файла; обязательные документы, ссылки и базовая проверка приватных данных прошли |
| Stop smoke | Браузер немедленно показывает остановку; реальный supervisor завершает owned process group; snapshot остается `stopping` до durable termination, затем execution становится `stopped`, а task — `cancelled` |

В `npm test` входят проверка установки локального npm-архива, прямой работы в проекте, режима без Git, границ чтения и записи, перепланирования, восстановления после остановки и связи требований с проверками. Пропущенные тесты требуют отдельной среды, в том числе Docker или Linux.

Браузерные и интеграционные сценарии используют **детерминированные ответы AI**. Файлы, HTTP, дочерние процессы и браузер в них настоящие. Это проверка системы, а не доказательство качества ответа выбранной модели на любой задаче.

UI дополнительно проверен на 1440×900, 1366×768, 1024×768 и 390×844: стабильный shell, один основной скролл задачи, отдельный скролл запусков, mobile drawer, reduced motion, русский error layer, раскрываемая диагностика и локальная загрузка Manrope без внешнего font request.

Live-smoke Codex на синтетическом проекте вне sandbox подтвердил успешный `ai-analyze`. Дальнейшее планирование было прервано `RUNTIME_DRIFT`, потому что runtime-код изменился во время прогона; это не provider failure, но и не подтвержденный полный автономный цикл с внешним AI. Внутри sandbox короткий запуск Codex завершился ненулевым кодом без сохранения raw stderr; точную причину того выхода тест не доказал. Публикация пакета, поддержка каждой ОС и готовность чужого production-проекта требуют отдельных фактических проверок.
