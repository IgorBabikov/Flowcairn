# Что проверено в версии 0.2.22

Проверки выполнены на macOS с Node.js 22.13.1 для локального кода `0.2.22`. Они подтверждают перечисленные сценарии, но сами по себе не означают публикацию в npm или завершение произвольной пользовательской задачи.

| Проверка | Результат |
| --- | --- |
| `npm test` | 612 успешно, 0 ошибок, 6 пропущены |
| `npm run typecheck` и `npm run lint` | Успешно |
| `npm run build` | Собран UI |
| `npm run test:ui` | Chromium: 73 успешно, 1 пропущен |
| `npm run test:proof-browser` | Реальный WorkflowService, HTTP и Chromium: требования, результаты проверок, устаревание результата и личная приемка |
| `npm run check:package` | В локальном устанавливаемом архиве 140 файлов; runtime, Skills, CLI и UI на месте |
| `npm run check:public` | 260 публичных файлов; обязательные документы, ссылки и базовая проверка приватных данных прошли |

В `npm test` входят проверка установки локального npm-архива, прямой работы в проекте, режима без Git, границ чтения и записи, перепланирования, восстановления после остановки и связи требований с проверками. Пропущенные тесты требуют отдельной среды, в том числе Docker или Linux.

Браузерные и интеграционные сценарии используют **детерминированные ответы AI**. Файлы, HTTP, дочерние процессы и браузер в них настоящие. Это проверка системы, а не доказательство качества ответа выбранной модели на любой задаче.

Полный автономный цикл с внешним AI в стороннем проекте пока **не подтвержден как завершенный**. Его нельзя представлять как успешный приемочный прогон. Публикация пакета, поддержка каждой ОС и готовность чужого production-проекта требуют отдельных фактических проверок.
