# Если запуск остановился

Сначала откройте статус, reason и receipt нужной попытки. Не удаляйте state и не исправляйте hashes вручную: это уничтожит связь между планом, действиями и результатом.

| Ситуация | Что делать |
| --- | --- |
| Нет `.flowcairn.json` | Выполнить `flowcairn init`, проверить профиль и сохранить setup в Git |
| Dirty checkout | Разобраться со своими изменениями; сохранить их обычным Git-процессом до task. Не делать автоматический reset/stash |
| AI provider unavailable | Проверить `doctor`, выбранную модель и локальную настройку сессии/ключа. Не отправлять credentials в issue |
| Docker/check image unavailable | Проверить Engine и выполнить `flowcairn checks prepare`; не запускать случайную host-команду вместо check |
| `failed` | Открыть failure и diff. Retry использовать только когда runtime явно разрешает его |
| `uncertain` | Выполнить разрешенный recovery. Убедиться, что старая попытка остановлена; продолжение требует нового плана |
| `stale`, runtime/profile/Skills drift | Подготовить новую версию плана; старое approval не переносится пересчетом hash |
| Review evidence >512 KiB | Разделить задачу. Не повышать лимит наугад и не заменять полный diff кратким summary |
| Нет локальной сессии UI | Запустить `flowcairn ui` и открыть новую ссылку из терминала |
| Порт занят | Использовать `flowcairn ui --port 4330`; не завершать незнакомый процесс |
| Revision/plan conflict | Обновить snapshot; решение должно относиться к актуальному run и plan |

## Потерян ответ на управляющий запрос

Тайм-аут может означать, что действие уже началось или завершилось. Кнопка повторения того же запроса сохраняет operation ID для безопасного чтения результата. Новый ID — новая операция, поэтому не создавайте его только из-за медленного ответа.

## Recovery не разрешает продолжение

Recovery подтверждает остановку и фиксирует состояние, но не превращает неизвестную попытку в `passed`. Новый план нужен, чтобы заново оценить оставшиеся изменения и проверки. Не удаляйте lock по возрасту: его владелец может продолжать работу.

## Как сообщить об ошибке

Укажите версию Flowcairn, ОС, Node, режим провайдера, точный error code и минимальный пример на синтетических данных. Не прикладывайте весь локальный store, session URL, `.env`, private diff или raw provider output.

## Новые проверки первого запуска

- `SYSTEM_TEMP_UNSAFE` / `RUNNER_TEMP_UNSAFE`: Codex-адаптер на macOS не выполняет проекты внутри системной временной папки. Используйте отдельный обычный рабочий каталог, например `~/Projects`. Не отключайте эту проверку.
- `SKILL_APPLICABILITY`: при подключении собственного Skill нужно явно выбрать этапы и область. В интерактивном `init` это короткие вопросы; файл не подключается ко всему проекту по умолчанию.
- `STALE_CONTEXT`: список или содержимое файлов изменились после просмотра. Обновите контекст и заново подтвердите актуальный исходный снимок.
- У задачи нет кнопки перехода к реализации: сначала разрешите и выполните AI-планирование. Кнопка появится, когда runtime подтвердит готовность предложения.
- `UNINSTALL_PROCESS_ACTIVE`: сначала закройте viewer и завершите операции. При неизвестном исходе используйте recovery. Историю и рабочие файлы нельзя удалять ради обхода проверки.

Настоящие npm-ссылки внутри проверенного дерева зависимостей учитываются toolchain отдельно. Ошибка о symlink в исходниках требует разбора пути; не добавляйте исходники в исключения зависимостей или outputs.
