# Если задача остановилась

Откройте главный экран задачи: обязательные требования, причину блокировки и связанные доказательства. Граф и receipts помогают разобрать техническую попытку. Не удаляйте state и не пересчитывайте hashes вручную.

| Ситуация | Что проверить |
| --- | --- |
| Исполнение завершено, но нет PROVEN | Откройте неподтвержденные требования: отсутствует проверка, evidence или выполненная работа. Число успешных этапов не заменяет coverage |
| Требование имеет метод `human` | Выполните указанную проверку, откройте связанные результаты и явно подтвердите требование с описанием наблюдения |
| Evidence stale | Результат изменился после проверки. Нужна новая допустимая проверка текущего состояния; старый receipt остается историей |
| Актуальность результата не подтверждена | Дождитесь успешного обновления или проверьте ошибку integrity. Прежний сертификат скрывается, пока состояние недоступно |
| `failed` | Откройте finding и результат проверки. Разрешенный repair выполняется автоматически в пределах бюджета; ручной retry доступен только по runtime capability |
| `uncertain` | Исход попытки не доказан. Используйте доступный recovery, чтобы подтвердить остановку; не повторяйте запись вслепую |
| Runtime/profile/Skills drift | Подготовьте актуальную версию плана. Старое согласование не переносится пересчетом hash |
| Лимит исправлений исчерпан | Сохраните доказательства и решите, как изменить оставшуюся работу. Не меняйте счетчик в JSON ради продолжения |
| AI-клиент недоступен | Проверьте `npx flowcairn doctor`, локальный вход в CLI и выбранную модель; после смены версии клиента повторите `setup` |
| Проверки выключены | Выберите нужный режим и scripts в настройке; отсутствие проверки не считается успехом |
| Docker image недоступен | Для режима `hardened` проверьте Engine и выполните `npx flowcairn checks prepare` |
| Неполный или слишком большой review bundle | Уменьшите задачу. Summary не подменяет требуемые исходные доказательства |
| Нет session-ссылки или она недействительна | Запустите `npx flowcairn` и откройте новую локальную ссылку из терминала |
| Порт занят | Используйте `npx flowcairn ui --port 4330`; не завершайте незнакомый процесс |
| Revision/plan conflict | Обновите состояние и повторите решение для актуального плана |

## Потерян ответ на действие

Тайм-аут не означает, что действие не произошло. Повтор того же запроса сохраняет operation ID, чтобы получить уже зафиксированный результат. Новый ID означает новую операцию. Не создавайте его только из-за медленного ответа.

## Recovery

Recovery фиксирует известное состояние и подтверждает остановку процесса; он не повышает `uncertain` до `passed` или PROVEN. Для продолжения может требоваться новый план. Возраст lock не доказывает, что его владелец прекратил работу.

## Установка и локальные границы

- `SYSTEM_TEMP_UNSAFE` / `RUNNER_TEMP_UNSAFE`: используйте обычный рабочий каталог вместо системной временной папки для Codex на macOS.
- `SKILL_APPLICABILITY`: при ручном подключении Skill задайте этапы и область через `--skill-actions` и `--skill-scope`.
- `STALE_CONTEXT`: файлы изменились после просмотра; обновите исходный контекст и подтвердите актуальный снимок.
- `UNINSTALL_PROCESS_ACTIVE`: остановите Flowcairn и разберите незавершенные операции перед удалением установки.
- Неизвестная `.ai-orchestrator` или конфликтующие инструкции: изучите существующую установку; Flowcairn не очищает ее автоматически.

В Git-проекте незакоммиченные изменения требуют осознанного выбора исходного снимка. Сохраните свои изменения или используйте предложенное подтверждение snapshot. В проекте без Git Flowcairn сверяет файлы текущего каталога. Автоматический reset/stash и удаление рабочих файлов не являются способом устранения ошибки.

## Сообщение об ошибке

Приложите версию Flowcairn, ОС, Node, провайдера, точный error code и минимальный пример на синтетических данных. Не отправляйте весь store, session URL, credentials, private diff или сырой provider output.
