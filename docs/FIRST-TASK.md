# Первая задача: от цели до PROVEN

Сначала выполните [установку](INSTALLATION.md). Откройте терминал в корне своего проекта и запустите:

```bash
npx flowcairn
```

При первом запуске Flowcairn предложит настройку, затем откроет интерфейс. Оставьте терминал работающим, пока выполняется задача. Для работы не нужны ручные task JSON и команды регистрации.

## 1. Заполните три поля

- **Заголовок:** коротко назовите результат, например «Регистрация компании».
- **Полное описание:** поведение, ограничения и критерии успеха.
- **Номер задачи:** ваш номер из tracker или другой понятный идентификатор.

Пример описания:

> Добавь форму регистрации. Нужны имя, email, пароль и подтверждение пароля. Для аккаунта компании дополнительно показывай название и ИНН. Объясняй ошибки рядом с полем, сохраняй введенные значения и не отправляй форму повторно во время обработки. Используй существующие компоненты. Не меняй API и зависимости.

Нажмите **«Запустить»**. Область разрешенного чтения и правила проверки уже определены при настройке; в форме задачи нет дополнительных технических полей.

## 2. Дождитесь анализа и плана

Flowcairn сохраняет цель и обязательные требования, изучает проект и составляет план. Для небольшой текстовой правки возможен короткий путь без отдельного анализа. Каждое требование получает способ проверки и связь с работой.

Когда план готов, откройте требования на главном экране задачи. Проверьте критерии, способы проверки и файлы, которые предлагается изменить.

## 3. При необходимости уточните план

Напишите дополнение прямо в панели плана. Например:

> Добавь переключатель видимости пароля. Он должен работать с клавиатуры и не отправлять форму.

Flowcairn сохранит исходную задачу и анализ, пересмотрит план и покажет актуальную версию. Перезапускать весь процесс или повторно заполнять форму не нужно. Старое согласование не переносится на измененный план.

## 4. Нажмите «Согласен»

Согласование относится к конкретным этапам, файлам, правам и ограниченному циклу исправлений. Claude Code/Cursor дополнительно требуют согласия на передачу данных для плана. Требование с личной приемкой подтверждается отдельно после исполнения.

Дальше Flowcairn выполняет реализацию, проверки проекта и отдельное ревью. При подтвержденной исправимой ошибке он проходит разрешенный цикл исправления и повторных проверок. Следить за каждым этапом не обязательно.

Если результат неизвестен, требуется больше прав или исчерпан лимит исправлений, работа остановится с объяснением. Это настоящая блокировка, а не завершенная задача. [Как восстановиться](TROUBLESHOOTING.md).

## 5. Проверьте готовый результат

Откройте каждое существенное требование и его evidence. **«Исполнение завершено»** означает окончание этапов. **PROVEN** появляется только при полном покрытии обязательных требований актуальными доказательствами.

Для требования с личной приемкой выполните указанную проверку, опишите результат и подтвердите его. Кнопка относится только к этому требованию и текущему состоянию файлов. Для PROVEN доступен сертификат с проверками и receipts. Изменение файлов делает прежние доказательства stale до повторной проверки.

Субъективную приемку Flowcairn оставляет вам. Он не делает commit, PR, push или deploy. Передайте проверенные изменения в обычный Git-процесс команды.

## Где искать подробности

Основной экран показывает ход работы и следующее решение. Receipts, точные версии, Skills и технические причины доступны в деталях этапа. Они нужны при разборе результата или сбоя, а не для заполнения каждой задачи.

## Изменение настроек

Закройте Flowcairn и выполните:

```bash
npx flowcairn setup
```

Здесь меняются модель, усиление, политика добавления тестов и режим выполнения существующих scripts. Для `trusted-local` отдельно подтверждается набор команд. Flowcairn показывает используемую конфигурацию; после ее изменения прежний план не получает новые права автоматически.
