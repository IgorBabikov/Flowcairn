# Руководство Flowcairn

Flowcairn выполняет задачу по сохраненному контракту и подтверждает обязательные требования актуальными доказательствами. Начните с [установки](INSTALLATION.md) и [первой задачи](FIRST-TASK.md).

| Что нужно | Документ |
| --- | --- |
| Установить пакет и подготовить проект | [Установка](INSTALLATION.md) |
| Поставить задачу, согласовать план и проверить результат | [Первая задача](FIRST-TASK.md) |
| Понять Requirements → Evidence → PROVEN | [Как работает Flowcairn](HOW-FLOWCAIRN-WORKS.md) |
| Узнать правила завершения и восстановления задачи | [Контракт выполнения](FLOWCAIRN-WORKFLOW.md) |
| Настроить AI, проверки и контекст | [Конфигурация](CONFIGURATION.md) |
| Применить правила команды на нужных этапах | [Skills](SKILLS.md) |
| Разобраться в границах AI-клиентов | [AI-клиенты](AI-HARNESS-INTEGRATION.md) |
| Разобрать остановку, stale или отсутствие evidence | [Решение проблем](TROUBLESHOOTING.md) |
| Изучить runtime и границы модулей | [Архитектура](ARCHITECTURE.md) |
| Проверить ограничения и фактически выполненные проверки | [Ограничения](LIMITATIONS.md), [проверки](VERIFICATION.md) |

Документы описывают реализацию в текущем исходном дереве. Результаты проверок и границы их применимости вынесены в один [отчет](VERIFICATION.md); описание возможностей не подтверждает публикацию новой версии в npm.
