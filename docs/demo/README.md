# Интерактивная запись Flowcairn

[Открыть опубликованную демо](https://igorbabikov.github.io/Flowcairn/).

Статическая страница позволяет выбирать моменты записи текущего интерфейса, исследовать узлы настоящего плана, их `needs`, статусы, hashes и идентификаторы отчетов. Это просмотр сохраненных данных, не онлайн-исполнитель. Подставные ответы AI явно отделены от настоящего Executor, файловых изменений и процессов проверок.

Сценарий: записать `2` в `counter.json`. Первая попытка пишет `1`, `verify.mjs` завершается с exit 1. Ограниченное исправление пишет `2`, проверка завершается с exit 0. После подставного review Executor выдает PROVEN. Внешнее изменение на `3` снимает подтверждение. Источник и время записи указаны в `media/recording.json`.

## Локальный просмотр

Весь сайт самодостаточен внутри этой папки. Для просмотра можно открыть `index.html` любым локальным HTTP-сервером; прямой file URL не поддерживает загрузку JSON во всех браузерах. Например, при установленном Python 3 из корня репозитория:

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory docs/demo
```

Откройте `http://127.0.0.1:8765/`. Сайт не содержит session token, API, credentials, аналитики или подключения к рабочему проекту.

## Обновление записи

Node.js 22, установленные devDependencies, Chromium Playwright и FFmpeg, librsvg (`rsvg-convert`) на macOS:

```sh
npm run build
node tools/readme-demo/capture.mjs
node tools/readme-demo/render-media.mjs
node tools/readme-demo/verify.mjs
```

Capture создает отдельный временный проект и удаляет его после закрытия сервиса. Приватные поля runtime не экспортируются: JSON формируется через явный список публичных полей. Полная сырая запись остается в игнорируемом `output/readme-demo/`.

GIF — монтаж шести настоящих кадров с подписями. MP4 — запись взаимодействия в реальном времени без звука. Картинки не имитируют несуществующие экраны. Все проверки относятся к этому детерминированному сценарию, не ко всем задачам и не к качеству внешнего AI.

## Публикация и лицензии

Workflow `.github/workflows/pages.yml` публикует только `docs/demo` из main через GitHub Pages. Папка исключена из npm-пакета через `docs/.npmignore`. Ссылки на технические документы ведут на GitHub; относительные пути не выходят за сайт.

UI и знак взяты из Flowcairn; происхождение ассетов: `tools/ai-graph-viewer/assets/rpg/ASSETS.md` и `THIRD_PARTY_NOTICES.md`. Шрифт Manrope: SIL OFL, лицензия в `fonts/OFL-Manrope.txt`. Новые AI-изображения не генерировались.
