# Участие в Flowcairn

Спасибо за конкретные воспроизведения, проверки и небольшие понятные изменения.

## Перед работой

Прочитайте [README](README.md), [архитектуру](docs/ARCHITECTURE.md) и [ограничения](docs/LIMITATIONS.md). Для заметного изменения поведения сначала заведите issue с проблемой, наблюдаемым результатом и границами. Уязвимости обсуждаются [приватно](SECURITY.md).

## Локальная разработка

Нужен Node.js 22:

```bash
npm ci
npm run build
npm run typecheck
npm run lint
npm test
```

Некоторые тесты используют временные локальные каталоги, loopback-сервер и браузер. Docker/реальные AI-проверки имеют отдельные предпосылки и не должны незаметно запускать платные внешние вызовы.

Меняйте только нужный scope. Сохраняйте границы runtimeRoot/projectRoot, immutable state, fail-closed permissions, idempotency и доказательства остановки. Не ослабляйте validator ради зеленого теста.

## Pull request

Опишите проблему и результат, затем проверки и ограничения. Для UI приложите скриншоты desktop/mobile на синтетических данных. Для contracts покажите negative/recovery tests. Для новой платформы укажите, что именно реально проверено.

Не включайте секреты, личные пути, корпоративный код, локальную историю запусков или session URL. Не добавляйте claims о скорости и качестве без сопоставимых измерений. Изменение запуска или конфигурации сопровождайте документацией.

Review конкретного diff и успешные проверки предшествуют merge. Не подменяйте человеческое решение self-report агента.
