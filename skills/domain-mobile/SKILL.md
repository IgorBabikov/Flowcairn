# Мобильные требования

- Определи платформу, навигацию, UI conventions и контракт данных. Не переноси задачу на web-инструментарий только из-за общего языка.
- Учти lifecycle, background, прерывание операции, offline/reconnect и восстановление по измененному сценарию.
- Для затронутой функции проверь запрос и отказ permissions, safe area, клавиатуру, доступность и хранение чувствительных данных средствами платформы.
- Разделяй evidence unit, emulator/simulator и физического устройства. Указывай реально проверенные платформы и версии; build или source-review не доказывают поведение на устройстве. Если подходящего verifier нет, нужна human acceptance, а не выдуманный pass.
