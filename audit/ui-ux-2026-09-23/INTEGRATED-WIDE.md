# Широкая компоновка в основном интерфейсе

Интеграция завершена 23 сентября 2026. Это текущая сборка основного frontend, а не отдельный прототип. Локальный стенд визуальной проверки: http://127.0.0.1:4360/.

## Результат

- От 1800 CSS px: проект и задачи слева (264px), рабочая область в центре, критерии и контекст справа (360–400px). Заголовок и главное действие находятся над рабочей областью.
- «Задача / Граф» занимают постоянное место. «Состояние проекта» доступно слева; «Детали исполнения» — в графе. Выбор работы открывает ее контекст и переход к отчетам именно этого узла.
- План показывает фактические работы, ожидаемые результаты и способы проверки из контракта. Отсутствующие способы проверки явно обозначены. Число работ и критериев не подгоняется под макет.
- Результат показывает требования и доказательства выбранного требования рядом. Отчет о выполнении свернут по умолчанию только в широком режиме.
- Ниже 1800 CSS px сохранена существующая компоновка. Введенные предложения к плану и текст ручной приемки сохраняются при изменении ширины.

## Контракты и границы изменения

Общие `PlanDecision` и `task-presentation` исключают отдельную логику согласования и статусов для широкого экрана. Backend handlers не изменены. Сохранены guards на capabilities, busy, актуальность revision/hash, challenge, права и неотправленные правки плана. Недостоверный snapshot не показывает старый сертификат; stale не превращается в подтверждение.

Все визуальные сценарии используют настоящую собранную UI-часть и синтетический API из тестовых fixtures. Это проверка интерфейса и его запросов, не доказательство реального выполнения задачи AI. Полный runtime с внешним AI не запускался.

## Ограничения

Этот этап закрывает широкую адаптацию, а не все P1/P2 исходного аудита. В частности, технический отчет проверки по-прежнему открывает JSON — его преобразование в человекочитаемую сводку остается отдельным замечанием аудита. Синтетические fixtures не подтверждают содержательную корректность реальных отчетов и реальную работу AI. Публикация, push и commit не выполнялись.
