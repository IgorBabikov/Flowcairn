# Поддержка

- Ошибка с воспроизведением: [создать issue](https://github.com/IgorBabikov/flowcairn/issues/new/choose).
- Предложение: опишите задачу пользователя, текущий обходной путь и ожидаемый результат.
- Уязвимость: только [приватный маршрут](SECURITY.md).

Перед обращением посмотрите [диагностику](docs/TROUBLESHOOTING.md). Укажите версию Flowcairn, ОС, Node, Docker и режим AI; приложите безопасный error code и минимальный пример на синтетических данных.

Не прикладывайте API-ключи, session URL, содержимое `.env`, абсолютные личные пути, весь state или чужой private diff. Наличие модели в публичном каталоге не означает доступ вашего аккаунта.

Проект развивается как open source. Гарантированные сроки ответа, коммерческая поддержка и совместимость с любым репозиторием не заявляются.
