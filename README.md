# Flowcairn

**Выполнение задач и разбор своего кода в 2D-мире.**

RPG-изменения еще не опубликованы в npm; описание ниже относится к текущим исходникам. Опишите задачу в Гильдии и подтвердите план. Flowcairn разбивает работу на небольшие этапы внутреннего графа, выполняет разрешенные изменения и запускает проверки проекта.

После этапа можно открыть сохраненный код в Мастерской или отложить разбор и продолжить. Режим «После всей задачи» сохраняет материалы без учебных пауз. Журнал хранит задачи и их версии; чтение не считается приемкой кода или доказательством освоенного навыка.

Подготовка AI-разбора пока проверена для Codex 0.156.1/0.157.1 на macOS. Доступность обучения проверяется отдельно от исполнения задач; [границы совместимости](docs/LIMITATIONS.md) указаны явно.

## Быстрый старт

Node.js 22 нужен самому Flowcairn. Язык исходников проекта не ограничен JavaScript: подключаются [команды проверок вашего стека](docs/CHECK-PROFILES.md). Flowcairn поставляет Codex и Claude Code CLI; их авторизация остается у выбранного клиента. Git и Docker для обычного запуска не требуются. [Установка и условия платформ](docs/INSTALLATION.md).

```sh
npm install -D flowcairn
npx flowcairn
```

Первый запуск предложит настройку и откроет интерфейс в браузере. [Как поставить первую задачу](docs/FIRST-TASK.md).

Codex, Claude Code или Cursor читает исходники по мере необходимости прямо в проекте, используя штатные tools и разрешения клиента. Executor применяет согласованные patches с проверкой путей и хешей. Зарегистрированные проверки запускаются локально в каталоге проекта; `npx flowcairn doctor` проверяет доступность компонентов.

Flowcairn проверяет собственный контекст и артефакты на известные секреты, но не изолирует все действия внешнего клиента или команд проекта. Дополнительная Git worktree остается отдельной настройкой существующего адаптера npm scripts. [Фактически выполненные проверки и ограничения платформ](docs/VERIFICATION.md).

По умолчанию исполнитель меняет файлы **текущего проекта** после согласования плана. Коммиты, PR и публикация остаются отдельными действиями. Непроверенные требования не считаются выполненными; граф и успешные тесты не гарантируют отсутствие любых ошибок.
