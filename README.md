## Зачем Flowcairn

Когда AI пишет код, легко получить готовое решение и пропустить его логику. Flowcairn связывает рабочую задачу с разбором написанного кода: что изменилось, как движутся данные и почему части программы связаны именно так.

Внутри сохраняется граф исполнения с небольшими этапами, проверками и прогрессом. Снаружи — игровой мир: поручение в Гильдии, работа и книга кода в Мастерской, прошлые задачи в Архиве.

## Быстрый старт

В каталоге своего проекта, с **Node.js 22**:

```sh
npm install -D flowcairn
npx flowcairn
```

Первый запуск предложит короткую настройку и откроет интерфейс в браузере.

**Дальше:** откройте Гильдию → опишите задачу → проверьте предложенный план и разрешения → начните выполнение.

[Первая задача по шагам](docs/FIRST-TASK.md) · [Установка и условия платформ](docs/INSTALLATION.md)

## Как это работает

| Место | Что вы делаете | Что делает система |
| --- | --- | --- |
| **Гильдия** | Описываете задачу и согласовываете границы работы | Анализирует задачу и предлагает план небольших этапов |
| **Мастерская** | Следите за работой, открываете код и учебный разбор | Выполняет разрешенные изменения, запускает проверки и сохраняет материал |
| **Архив** | Возвращаетесь к прошлым задачам и их материалам | Хранит версии задач, результаты и историю |

Перемещение по миру не запускает работу. Исполнение требует явного решения; внутренний граф, отчеты и восстановление доступны в книге диагностики.

### Разбор в вашем темпе

- **После этапа:** система останавливается на учебную паузу. Можно открыть материал или явно отложить разбор и продолжить работу.
- **После всей задачи:** работа идет без учебных пауз, материалы сохраняются для последующего изучения.

В книге — сохраненный код, его изменения, объяснение выполнения и движения данных. Код доступен для чтения и копирования; писать его внутри Flowcairn не требуется. Подготовка AI-объяснения запускается отдельным действием, когда провайдер и разрешения позволяют это сделать.

<img src="https://raw.githubusercontent.com/IgorBabikov/Flowcairn/main/.github/media/flowcairn-frontend-codebook.jpg" width="960" alt="Книга кода Flowcairn: разбор frontend-поиска товаров и JavaScript-код защиты от устаревших ответов" />

*Демонстрационная frontend-задача: поиск товаров на JavaScript. Пользователь вводит «рюкзак», затем «термос»; разбор объясняет, почему поздний ответ первого запроса не меняет выдачу. Данные учебные, внешний AI при съемке не запускался.*

Чтение не считается приемкой кода или доказательством освоенного навыка. [Как проверить пользу обучения](docs/LEARNING-PILOT.md).

## Ваш проект, ваш язык

Node.js нужен самому Flowcairn; язык исходников проекта не ограничен JavaScript. Для своего стека подключите [команды проверок](docs/CHECK-PROFILES.md). Если нужного компилятора или проверки нет, система сообщает об ограничении.

Flowcairn поставляет Codex и Claude Code CLI. Их авторизация остается у выбранного клиента. Git и Docker для обычного запуска не требуются.

**Текущая граница обучения:** подготовка AI-разбора проверена для Codex 0.156.1/0.157.1 на macOS. Доступность обучения проверяется отдельно от исполнения задач. [Совместимость и ограничения](docs/LIMITATIONS.md).

## Контроль над выполнением

По умолчанию исполнитель меняет файлы **текущего проекта** после согласования плана. Коммиты, PR и публикация остаются отдельными действиями.

- **План перед изменениями.** Codex, Claude Code или Cursor читает исходники средствами выбранного клиента. Executor применяет согласованные изменения с проверкой путей и хешей.
- **Проверки вашего проекта.** Зарегистрированные команды запускаются локально. Непроверенные требования не считаются выполненными.
- **Материал связан с версией кода.** Сохраненные исходники и отчеты помогают вернуться к конкретному решению; устаревание материала показывается отдельно.

Граф и успешные тесты не гарантируют отсутствие любых ошибок. Flowcairn проверяет собственный контекст и артефакты на известные секреты, но не изолирует все действия внешнего клиента или команд проекта. Дополнительная Git worktree остается отдельной настройкой существующего адаптера npm scripts.
