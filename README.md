# Flowcairn

**Сложная задача. Понятный план. Проверенный результат.**

Опишите задачу и подтвердите план. Flowcairn выполнит разрешенную работу в вашем проекте, проверит требования и попробует исправить найденные проблемы в пределах задачи.

В итоге видно, что изменилось, какие проверки прошли и что еще требует вашего решения. Непроверенные требования не считаются выполненными.

## Быстрый старт

Нужны Node.js 22, проект с `package.json` и настроенный AI-клиент. Git не обязателен, Docker не требуется. [Клиенты и платформы](docs/INSTALLATION.md).

```sh
npm install -D flowcairn
npx flowcairn
```

Первый запуск предложит настройку и откроет интерфейс в браузере. [Как поставить первую задачу](docs/FIRST-TASK.md).

Codex, Claude Code или Cursor читает исходники по мере необходимости прямо в проекте, используя штатные tools и разрешения клиента. Executor применяет согласованные patches с проверкой путей и хешей. Зарегистрированные проверки запускаются локально в каталоге проекта; `npx flowcairn doctor` проверяет доступность компонентов.

Flowcairn проверяет собственный контекст и артефакты на известные секреты, но не изолирует все действия внешнего клиента или scripts. Дополнительная Git worktree доступна по выбору для организации ветки. Поддерживаются macOS, Linux и нативный Windows; WSL и Docker не требуются. [Границы проверок](docs/VERIFICATION.md).

Сейчас инструмент рассчитан на разработку в Node.js-проектах и по умолчанию меняет файлы **текущего проекта**. Коммиты, PR и публикация остаются отдельными действиями. [Ограничения](docs/LIMITATIONS.md).
