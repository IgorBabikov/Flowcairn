# Flowcairn

### AI выполняет задачу. Вы понимаете свой код.

Flowcairn превращает задачу в проверяемый рабочий процесс: от исследования и плана до изменений, доказательств и обучения на реальном потоке кода.

## Что это

Когда AI пишет код, получить ответ легко. Сложнее понять, что именно изменилось, почему это работает и сможете ли вы сами изменить решение завтра.

Flowcairn держит эти вещи вместе:

- задача, требования и неизвестные;
- план, который человек подтверждает до записи файлов;
- исполнение AI с правами, хешами, зависимостями и ограниченными исправлениями;
- проверки, findings и доказательства по каждому требованию;
- книга кода с реальными файлами, связями, потоком данных и практикой объяснения.

## Быстрый старт

В корне проекта с Node.js 22:

```sh
npx flowcairn
```

Flowcairn предложит короткий onboarding и откроет локальный интерфейс. Git и `package.json` не обязательны для direct-запуска. Для терминала без автоматического открытия браузера:

```sh
npx flowcairn --no-open
```

Дальше: откройте **Гильдию**, опишите задачу, проверьте план и разрешения, затем запустите выполнение.

## Как работает

| Этап | Что видит разработчик | Что сохраняет Flowcairn |
| --- | --- | --- |
| Гильдия | задача, требования, неизвестные и план | immutable task contract и согласование |
| Мастерская | работа героев, зависимости, проверки и блокировки | receipts, hashes, findings и состояние Executor |
| Книга кода | измененные участки, связи, данные и вопросы | source-bound материал, главы и практика |
| Архив | прошлые задачи и версии материала | исторические результаты с отметкой stale |

Ни один статус «готово» не принимается на веру. `PROVEN` появляется только когда обязательные требования связаны с допустимой проверкой и актуальным evidence.

## Три AI-клиента

- **Codex** — поставляется проверенная базовая версия, модель и reasoning могут наследоваться из конфигурации CLI.
- **Claude Code** — подключается через официальный CLI и его авторизацию.
- **Cursor** — подключается через официальный Cursor Agent CLI; native learning включается только после отдельной проверки профиля и политики.

Flowcairn не создает аккаунты, не передает credentials и не подменяет permission controls. Реальный inference зависит от авторизации клиента. Поддержка каждого клиента и режима проверяется отдельно.

## Обучение на своем коде

Можно выбрать разбор после этапа или после всей задачи. Материал привязан к конкретной версии исходников и показывает:

- каждый измененный участок и необходимый контекст;
- вызовы, поток данных, состояние, типы и обработку ошибок;
- причины решений и последствия изменения;
- наблюдаемые значения только из зарегистрированного extractor;
- главы, вопросы, подсказки и сохраненные ответы.

Чтение не считается доказательством понимания. Ответ разработчика и его оценка хранятся отдельно от `PROVEN` результата задачи.

## Мастерская гильдии

Это рабочее представление процесса, а не декоративная анимация. Выразительные RPG-герои показывают реальные состояния: анализируют, планируют, изменяют код, проверяют, исправляют, ждут зависимость и передают результат дальше. Движение и реплики создаются из сохраненного состояния и receipts, а не из таймера.

Актуальные герои и ассеты входят в пакет; отвергнутые бытовые персонажи в активную сцену не входят.

## Честная граница текущего релиза

- Поддерживаемые ОС: **macOS и native Windows**. Linux и WSL исключены из текущей реализации.
- Codex проверен локально. Claude Code и Cursor без авторизованных аккаунтов проверяются через native-no-inference и симуляторы; это не live inference.
- Native Windows CI настроен, но отдельный завершенный Windows-host прогон нужен перед окончательным release claim.
- Hardware performance на M1 и реальное влияние обучения на навыки требуют отдельной приемки.
